About this project

A real-world data analytics web app for colleges.

What it does

CSV upload at runtime → Pandas validation & cleaning → descriptive analytics → interactive Plotly dashboard → auto-generated insights → downloadable HTML report. No dataset is hardcoded; every chart hides gracefully when its columns are absent, and insights are always computed from the uploaded file — never fabricated.


Tech stack

Python · Flask · Pandas · NumPy · Plotly · HTML · CSS · Vanilla JavaScript. Deliberately beginner-friendly: Flask serves pages + JSON, JS renders charts, analysis lives in analysis/.

Column intelligence

Case-insensitive matching, e.g. attendance %, attendance_percentage → attendance; marks, total marks, final score → score. Subjects detected by keyword. Missing concept ⇒ section hidden.


Explain it in an interview (60 seconds)

"Users upload any student CSV. I normalise headers and map variations to canonical fields, clean with median/mode imputation and duplicate removal, compute KPIs, correlations and segments in Pandas, expose them as JSON from Flask, and render responsive Plotly charts. Insights and recommendations are generated from the computed statistics, and the report endpoint exports them as HTML."
